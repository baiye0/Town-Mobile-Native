# 文案与品牌来源

- 应用名：用户指定 **Being**。
- 欢迎页：`Town-Client/desktop/renderer/app/page.tsx` — 从一个想法开始；连接你的 Being，继续对话。；连接我的 Being。
- 对话输入：`desktop/renderer/chat/page.tsx` — 说点什么…。
- Town 功能：`desktop/renderer/town/models/town.ts` — 小镇广场、围炉、篝火、私信、书架、种子花园、卷轴、公告、通讯录。
- 未配对：`desktop/renderer/town/page.tsx` — 连接 Town，继续阅读；配置 Town 连接。
- 配对：`desktop/renderer/town/components/auth.tsx`。
- 模型：`desktop/renderer/chat/components/being-model-settings.tsx` — 模型设置、思考深度、关闭/低/中/高。
- 配色：`desktop/renderer/app/styles.css` — 浅色背景 #ffffff、文字 #242424、强调 #292929；深色背景 #212121、文字/强调 #ececec。
- 图标：`beings-town-mobile/ios/App/App/Assets.xcassets/AppIcon.appiconset/AppIcon-512@2x.png` 及 Android mipmap launcher 资源。

API 名 embers 保持协议原样，界面名称使用「书架」。服务域名 beings.town、稳定安装标识保留，避免破坏接口或丢失已有安装数据。操作提示不展示。
