# Being Android v0.1.1

本次更新改善长对话、流式回复与键盘交互，保留双方聊天气泡。

- 流式正文按消息更新，长回复分段加载，减少持续接收内容时的卡顿。
- 修复回复出现在发送消息上方的问题，保持时间、提问和回复的顺序。
- 查看历史或阅读长回复时保留阅读位置，避免新内容、历史刷新及键盘开关意外恢复底部跟随。
- 历史刷新及错误状态统一显示在顶部，减少消息区与输入栏的布局变化。
- 调整浅色、深色气泡及输入栏；键盘与底部导航连续过渡。
- 将被打断的回复准确显示为“上一条回复已打断”，兼容已有本地记录。

验证：96 项 Android 单元测试、Release Lint、12 项真机滚动回归通过；真机组合测试覆盖约 1.9 万字流式回复、上下滑动和 3 次输入法开关。真实服务端聊天全链路及所有设备表现不在本次测试覆盖范围内。

Android 9 及以上；包含 ARM64、x86_64 Portal。使用与 v0.1.0 相同的正式签名，可直接覆盖升级并保留本地数据。版本码：3。
