Being Android 0.1.0 首个正式签名版本。

- 内置固定版本的 Android Portal，支持 ARM64 和 x86_64。
- 接入日历、通讯录、提醒、分享、通知、位置和健康等手机能力，按 Being 授权，并校验 Android 实际权限。
- 修复思考详情默认折叠状态，完善授权刷新、撤销和待执行操作保护。
- CI 执行单元测试、Lint、Release 构建、签名及 Portal 16 KB 对齐检查。

安装包为 `town.beings.nativeapp`，支持 Android 9 及以上。正式版使用独立固定签名，与此前本地/CI Debug 包签名不同，无法直接覆盖 Debug 包。安装前请保留原应用中的重要数据。

仓库为私有仓库，下载需要有访问权限的 GitHub 账号；当前应用内匿名更新接口无法访问私有 Release。此流程不会安装到任何手机。
